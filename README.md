# Financial Dashboard

A modern financial dashboard built with Streamlit, featuring real-time stock data analysis, interactive charts, and subscription plans.

## Features

- Real-time stock data visualization
- Interactive candlestick charts
- Volume analysis
- Key financial metrics
- Subscription plans with different tiers
- Modern, responsive design

## Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd financial_dashboard
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage

Run the dashboard:
```bash
streamlit run app.py
```

The dashboard will be available at `http://localhost:8501`

## Structure

- `app.py`: Main dashboard application
- `pages/1_📊_Pricing.py`: Pricing plans page
- Additional pages will be added for more features
