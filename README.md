# Financial Dashboard

A modern financial dashboard built with Streamlit that provides comprehensive financial analysis and visualization tools. This dashboard incorporates features from the FinanceToolkit library to provide in-depth financial analysis.

## Features

- 📈 Real-time stock price tracking and visualization
- 📊 Financial statement analysis (Income Statement, Balance Sheet, Cash Flow)
- 📉 Technical indicators and performance metrics
- 💰 Key financial ratios and metrics
- 📱 Modern, responsive UI design
- 🔍 Stock search and comparison tools

## Installation

1. Clone this repository:
```bash
git clone https://github.com/yourusername/financial-dashboard.git
cd financial-dashboard
```

2. Install the required packages:
```bash
pip install -r requirements.txt
```

3. Run the dashboard:
```bash
streamlit run app.py
```

## Usage

1. Launch the dashboard using `streamlit run app.py`
2. Use the sidebar to search for stocks and select analysis options
3. View real-time data and analysis in the main panel

## Structure

- `app.py`: Main dashboard application
- `utils.py`: Helper functions for data processing and analysis
- `requirements.txt`: Project dependencies
- `README.md`: Project documentation

## Data Sources

Currently using mock data for demonstration. To use real data:
1. Obtain an API key from your preferred financial data provider
2. Update the configuration in the dashboard
3. Replace mock data functions with real API calls
